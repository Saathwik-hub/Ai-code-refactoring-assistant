System Architecture & Roadmap

AI Code Refactoring Assistant

A high-performance developer workspace engineered to prepare source code files for next-generation automated AI code refactoring.

✅ Phase 1 (MVP) Completed Capabilities

  • ✓ Monaco Editor Workspace: Full syntax highlighting, auto-indentation, line numbers, code folding, AMD loader integration, and theme sync.
  • ✓ Drag-and-Drop File Upload: Supports `.py`, `.java`, `.js`, `.ts`, `.cpp`, `.c`, `.html`, `.css`, and `.json` with file size validation (5MB max).
  • ✓ Language Detection: Automated syntax matching and filename extension detection with manual language selector.
  • ✓ Syntax Validation Engine: Python AST parsing, JSON decoding, JS/TS/C/C++/Java bracket balance checks, and diagnostics panel.
  • ✓ Sidebar File Explorer: Tree view of uploaded files with create, rename, delete, download, and file opening actions.
  • ✓ Developer Dashboard: Metrics analytics, code line counters, language distribution badges, recent activity logs.
  • ✓ Authentication & Themes: Developer login, registration, password visibility toggle, and persistent dark/light themes.
  • ✓ FastAPI Backend: REST API routes (`/api/auth`, `/api/files`, `/api/syntax`) ready for modular AI integration.

🚀 Phase 2 (Future Integration) Roadmap

🤖 Ollama / LLM AI Refactoring
Integrate local Ollama models (Llama 3, DeepSeek-Coder, CodeLlama) for automated code refactoring.
📊 Code Complexity Analysis
Cyclomatic complexity scores, maintainability index calculations, and code smell detection.
🔄 Side-by-Side Diff Viewer
Interactive visual code diffing showing original source vs AI-refactored output before accepting changes.
💬 AI Chat Coding Assistant
In-editor conversational side panel to ask questions about code structure, performance, and unit tests.
